# Nodomic

<img src="./docs/design-system/assets/knot-mark.svg" width="72" alt="Nodomic">

Comparte herramientas de tu oficio. Abre un flujo de la comunidad, adapta sus nodos y prueba el resultado con tus propios datos. El agente prepara un borrador y tú decides qué cambios aplicar.

Por ejemplo, una profesora puede adaptar un flujo para que conserve los ceros al filtrar mediciones vacías y publicar la mejora para su clase.

[Abrir Nodomic](https://nodomics-web.onrender.com) · [Guía del proyecto](project-description.md) · [Arquitectura](docs/engineering/arquitectura.md)

## Desarrollo local

Usa Node.js 24 o superior y pnpm 10.28.1.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Para conectar las cuentas y el agente, consulta la [configuración de ejemplo](apps/web/.env.example).
